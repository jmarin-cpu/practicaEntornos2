# Librería Página 404 – Práctica de depuración

Página web de un negocio ficticio. **Tiene un fallo**: encuéntralo y corrígelo siguiendo el enunciado de la práctica.

## Estructura

```
index.html
css/
  style.css
```

## Cómo debería verse la página

- **Cabecera** de color oscuro con el nombre "Librería Página 404" a la izquierda y el menú (Novedades, Horario, Contacto) en horizontal a la derecha, en blanco, sin viñetas ni subrayado.
- **Portada** de color con texto blanco centrado y un botón de color destacado "Ver novedades".
- **Novedades**: tres tarjetas blancas (El último commit, CSS para humanos, Cómic: Bug Hunters), con bordes redondeados y sombra, colocadas una al lado de otra.
- **Horario** sobre un fondo suave, centrado.
- **Pie** de color oscuro con la dirección centrada.
- Tipografía sin serifa (Arial) en toda la página.
